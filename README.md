# SplitTab

SplitTab is a React Native + Expo mobile app for shared household expense tracking.

## Prerequisites

- Node.js 18+
- npm
- Expo Go app on your phone (optional, for physical device testing)

## Getting Started

1. Install dependencies:

   npm install

2. Create environment file:

   cp .env.example .env

3. Start the app:

   npx expo start

4. Open on device:
   - iOS: scan QR with Camera app
   - Android: scan QR inside Expo Go

## Navigation Approach

For this project, navigation is planned with **React Navigation**.
